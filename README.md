# Priti — Personal Marketing Website

A simple, modern two-page personal marketing website for a university student.

## Pages
- `index.html` — Home / personal brand
- `about.html` — About, projects, skills and contact

## Image
The exact homepage visual is stored at:
`assets/hero-image.png`

## Run locally
Open `index.html` in a browser, or use a local server such as VS Code Live Server.

## Vercel
This is a static site. Import the GitHub repository into Vercel and deploy with no build command required.

## Before publishing
Replace `your-email@example.com` and the placeholder GitHub/LinkedIn links in `about.html` with your real links.
